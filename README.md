### Decentralized Document Verification DApp

> SecDoc UI is a decentralized application (DApp) built to verify, register, and authenticate documents on-chain.  
> It provides tamper-proof document validation using blockchain technology.

---

## 🌍 Overview

SecDoc enables:

- 📄 Secure document registration on-chain  
- 🔎 Instant public verification  
- 🔐 Tamper-proof hash validation  
- 🧾 Transparent ownership & issuance records  

The platform ensures that once a document is registered, its authenticity can always be verified without relying on centralized authorities.

---

## 🚀 Core Features

### 📌 Document Registration
- Upload document
- Generate cryptographic hash
- Store hash on blockchain
- Assign issuer identity

### 🔍 Document Verification
- Upload document to verify
- System regenerates hash
- Compares with on-chain record
- Returns authenticity status

### 👤 Issuer Dashboard
- Register new documents
- View issued records
- Monitor verification activity

### 🌐 Public Verification Portal
- Anyone can verify a document
- No login required for validation
